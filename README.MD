# Интеллектуальные беспилотные системы

Ссылка на рендер сайта
https://practice-2025.onrender.com

Статический сайт о проекте по созданию и тестированию исполнительных механизмов для беспилотного транспорта на базе KIA Ceed. В рамках работы реализованы:
- Исследование и интеграция актуатора тормоза
- Разработка схемы управления и программного обеспечения
- Проведение испытаний и анализ результатов
- Оформление технической документации

Сайт содержит аннотацию, описание этапов, команду, журнал прогресса и полезные ресурсы.
